UI 갤러리 데스크톱 도우미 화면 추가와 앱별 UI 갤러리 개편

포근해용 웹 서비스의 과거 운영 및 최신 스냅샷 아카이브(실제 LOPEC 공개 순위표 기반 랭킹 스냅샷 등 포함)에 이어, 로컬에서 개발 및 검증 중인 Windows 데스크톱 도우미의 주요 기능 화면을 둘러볼 수 있는 앱별 UI 갤러리(/ui/)를 공개합니다. 실시간 전투 보조·파티 신청자 판독·보상 상자 골드 환산·아크 그리드 장착 코어 및 젬 개선 등 9개 핵심 메뉴와 게임 오버레이 구동 화면을 확인하실 수 있습니다. 데스크톱 화면에 표시된 캐릭터·시세·계정·상자 환산 등 수치는 로컬 검증용 가상 자료이며, 실제 게임 플레이나 정식 배포 패키지가 아닌 출시 전 검증본임을 함께 안내해 드립니다.

데스크톱 도우미 화면 모음 신설

  • 9개 메뉴와 게임 오버레이 20개 화면 상태: 홈(실시간)·캐릭터 분석·아크 그리드 젬·코어 장착 및 개선 젬 배치·경매 분배금·숙제 현황·출석 연동·화면 설정·연결 안내 등 9개 핵심 메뉴와 전투 보조·파티 신청자·지옥 및 나락 보상 상자 오버레이를 포함한 총 20개 화면 상태를 고화질로 기록했습니다.
  • PC 전용 환경 안내: 데스크톱 도우미는 Windows PC 전용 프로그램으로 모바일 화면은 지원하지 않으며, 갤러리 내에서도 PC 전용 배지와 안내를 통해 명확히 구분합니다.

로컬 검증 및 시험 환경 고지

  • 데스크톱 화면의 가상 자료 기반: 데스크톱 화면에 표시된 캐릭터 정보, 시세, 숙제 및 출석 데이터는 모두 로컬 임시 서버에서 제공된 가상 합성 자료이며 실제 게임 유저 정보나 실시간 거래소 시세가 아닙니다. 기존 웹 아카이브의 랭킹 스냅샷 등은 당시 공개된 순위표를 바탕으로 한 정적 기록입니다.
  • 직접 그린 중립 시험용 장면 창: 오버레이 화면의 배경 게임 장면은 직접 그린 중립적인 시험용 장면 창을 바탕으로 캡처한 것이며, 실제 게임 플레이 화면이 아닙니다.
  • 미출시 로컬 검증본: 서명되지 않은 패키지는 외부에 배포하지 않으며, 현재 공식 서비스 출시나 다운로드를 제공하지 않는 로컬 검증본입니다.

갤러리 탐색 기능 강화

  • 앱별 필터 및 맞춤 그룹: 웹 서비스와 데스크톱 도우미를 나누어 보거나 함께 모아볼 수 있는 앱 필터가 추가되었으며, 선택한 앱에 따라 분류 탭이 알맞게 정돈됩니다.
  • 모바일 보기 안전 처리: 모바일 기기 뷰 선택 시 PC 전용 화면은 숨김 처리되며, 즉시 PC 뷰로 전환할 수 있는 안내 버튼을 제공합니다.
