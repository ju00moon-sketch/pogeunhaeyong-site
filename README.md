# 포근해용 홈페이지

[홈페이지](https://ju00moon-sketch.github.io/pogeunhaeyong-site/) · [랭킹 스냅샷](https://ju00moon-sketch.github.io/pogeunhaeyong-site/ranking.html) · [젬 도우미](https://ju00moon-sketch.github.io/pogeunhaeyong-site/gem-helper.html) · [UI 갤러리](https://ju00moon-sketch.github.io/pogeunhaeyong-site/ui/) · [업데이트 노트](https://ju00moon-sketch.github.io/pogeunhaeyong-site/updates.html)

포근해용의 이용 안내와 정적 도구, 버전별 변경사항을 제공하는 공개 정적 웹사이트입니다.
실시간 캐릭터 검색, 거래소 시세 조회, 분배금·재련 계산, 로그인 세션, 개인 숙제표 저장, 길드 일정 및 출석 등 서버 기능은 [기존 운영 서비스](https://pogeunhaeyong.duckdns.org/)로 연결됩니다. 운영 서비스는 이번 사이트 개편 이전 화면으로 유지됩니다.

### 홈 화면 복원 안내
짙은 남색 바탕과 성채 일러스트 배경, 황금색 포인트의 검색창과 바로가기 배너를 복원하여 포근해용 고유의 디자인을 제공합니다. 상단 헤더와 하단 푸터를 통해 모든 공개 페이지로 자유롭게 이동하실 수 있습니다.

### 공개 랭킹 스냅샷 안내 (/ranking.html)
로펙(LOPEC) 공개 랭킹 화면에서 확인된 딜러 상위 100위 및 서포터 상위 100위 캐릭터 정보의 정적 스냅샷입니다.
- **수집 시각 명시**: 각 스냅샷의 수집 완료 시각(한국 시간 KST)을 화면 상단에 명시합니다.
- **역할별 상위 100위 제공**: 딜러 TOP 100과 서포터 TOP 100 보드를 분리하여 제공하며, 보드 내에서 서버 및 직업 필터, 캐릭터명 검색을 지원합니다.
- **정적 자료 한계 안내**: 본 페이지는 특정 시점에 수집된 정적 스냅샷으로, 실시간 순위나 전체 캐릭터 조회가 아니며 자동 주기 갱신을 지원하지 않습니다.
- **자료 완전성 및 순위 유지**: 숨겨진 정보를 복원하거나 수집하지 않으며, 불완전하거나 비정상적인 입력은 기존의 완전한 수집 자료를 덮어쓰지 않습니다. 필터를 적용해도 수집 시점의 원래 순위 번호는 유지됩니다.

### 아크 그리드 젬 가공 도우미 안내 (/gem-helper.html)
게임 내 아크 그리드 젬 가공의 최적 선택지를 브라우저에서 안내해 드리는 보조 도구입니다.
- **브라우저 로컬 처리**: 게임 화면 공유(Screen Capture API) 및 가공창 캡처 이미지 파일 업로드(최대 15MiB)를 지원합니다.
- **프라이버시 및 보안**: 공유된 화면이나 업로드된 이미지는 브라우저 내부 메모리에서만 OCR 분석되며 외부 서버로 전송되거나 저장되지 않습니다. 게임 자동 조작이나 매크로 동작은 일절 포함하지 않습니다.
- **직접 목표 설정 및 추천**: 원하는 옵션을 직접 지정하여 각 선택지별 달성 확률을 높이는 행동을 안내받을 수 있습니다. 내 캐릭터 정보 연동 자동 목표 API는 운영 서버 전용 미출시 기능으로, 본 정적 사이트에서는 직접 목표 설정을 이용합니다.

### 정적 사이트 경계 및 운영 서비스 분리
본 웹사이트는 GitHub Pages 정적 호스팅 환경에서 구동됩니다.
- **정적 안내 및 브라우저 도구**: 홈 안내, 랭킹 스냅샷, 아크 그리드 젬 가공 도우미(직접 목표/화면 처리), UI 갤러리, 버전별 업데이트 노트는 브라우저에서 바로 이용하실 수 있습니다.
- **서버 연동 기능의 운영 서비스 이동**: 로그인 세션, 개인 숙제표 저장, 길드 일정 및 출석 관리, 실시간 캐릭터 검색, 실시간 거래소 및 보석 시세 조회, 분배금 및 재련 계산 도구는 별도의 운영 서비스(https://pogeunhaeyong.duckdns.org/)에서 제공됩니다. 자동 이동 없이 이용자가 직접 링크를 눌러 이동하도록 구성되어 있습니다.
- **운영 서비스 화면 안내**: 외부 운영 서비스는 이번 사이트 개편 이전 화면으로 유지되며, 기존 가입 및 인증 정책대로 동작합니다.

### UI 모음 갤러리 안내 (/ui/)
[UI 갤러리](https://ju00moon-sketch.github.io/pogeunhaeyong-site/ui/)는 이전 운영 서비스의 디자인, 2026-10-15 기준 이전 공개·후보 화면(공개 16개·후보 31개), 그리고 2026-10-16 기준 최신 전체 홈페이지 스냅샷을 한곳에 모아 페이지·기기·테마별로 비교해 볼 수 있는 아카이브입니다.
- **모음 범위**: 이전 운영판(47개), 이전 공개·후보판(47개, 공개 16개 및 미출시 후보 31개), 최신판의 홈·랭킹·캐릭터·도구·숙제표·길드·계정·문서·업데이트 노트 등 주요 화면을 데스크톱(1280px)과 모바일(390px / 320px), 다크 모드와 라이트 모드로 제공합니다.
- **기록 시점의 화면 보존**: UI 갤러리는 기록 당시의 화면 상태를 보존한 모음이며, 기존 94개 화면과 784개 이미지는 역사적 기록으로 온전히 보존됩니다. 후보 화면에는 미출시 후보 화면 배지가 유지됩니다.
- **검증용 가상 자료 고지**: 미출시 서비스 화면에 표시된 계정명, 캐릭터 정보, 시세, 일정, 수치는 화면 구조와 빈 상태를 검증하기 위해 생성한 가상 자료이며, 실제 이용자나 길드의 개인정보 및 실제 시세·운영 사실이 아닙니다.
