# 포근해용 홈페이지

[홈페이지](https://ju00moon-sketch.github.io/pogeunhaeyong-site/) · [업데이트 노트](https://ju00moon-sketch.github.io/pogeunhaeyong-site/updates.html) · [출시 예정 안내](https://ju00moon-sketch.github.io/pogeunhaeyong-site/updates/upcoming.html)

포근해용의 이용 안내와 버전별 변경사항을 제공하는 정적 홈페이지입니다.
캐릭터 조회·도구 계산·로그인·개인 숙제표·길드 일정은 [기존 서비스](https://pogeunhaeyong.duckdns.org/)로 연결됩니다.

출시 예정 안내에 적힌 서비스 기능은 기존 운영 홈페이지에 아직 반영되지 않았습니다.
정적 안내 페이지의 게시와 실제 서비스 기능의 반영은 구분합니다.

코드의 이용 조건은 [MIT License](LICENSE), 글꼴의 이용 조건은 [OFL](assets/fonts/OFL.txt)을 참고해 주세요.
게임·이미지·이모티콘의 권리는 각 권리자에게 있습니다.
