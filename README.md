# 포근해용 홈페이지

[홈페이지](https://ju00moon-sketch.github.io/pogeunhaeyong-site/) · [UI 갤러리](https://ju00moon-sketch.github.io/pogeunhaeyong-site/ui/) · [업데이트 노트](https://ju00moon-sketch.github.io/pogeunhaeyong-site/updates.html) · [출시 예정 안내](https://ju00moon-sketch.github.io/pogeunhaeyong-site/updates/upcoming.html)

포근해용의 이용 안내와 버전별 변경사항을 제공하는 정적 홈페이지입니다.
캐릭터 조회·도구 계산·로그인·개인 숙제표·길드 일정은 [기존 서비스](https://pogeunhaeyong.duckdns.org/)로 연결됩니다.

### UI 모음 갤러리 안내
[UI 갤러리](https://ju00moon-sketch.github.io/pogeunhaeyong-site/ui/)는 이전 운영 서비스의 디자인과 현재 공개 정적 홈, 그리고 준비 중인 미출시 서비스 화면을 한곳에 모아 페이지·기기·테마별로 비교해 볼 수 있는 모음입니다.
- **모음 범위**: 이전 운영판, 현재 공개 정적판, 미출시 후보판의 홈·캐릭터·도구·숙제표·길드·계정·문서·업데이트 노트 등 주요 화면을 데스크톱(1280px)과 모바일(390px), 다크 모드와 라이트 모드로 제공하며 갤러리 검증 화면(1280px / 320px)에서 전환해 확인할 수 있습니다.
- **미리보기 및 가상 자료 구분**: 미출시 서비스 화면은 정적 갤러리에서 시각적 구조를 살펴보는 미리보기 전용입니다. 가상 데이터가 표시된 화면의 계정명, 캐릭터 정보, 시세, 일정, 수치는 화면 구조와 빈 상태를 검증하기 위해 생성한 가상 자료이며, 실제 이용자나 길드의 개인정보 및 실제 시세·운영 사실이 아닙니다. 가상 데이터가 없는 문서나 빈 상태 화면에는 해당 안내를 적용하지 않습니다.
- **운영 반영 구분**: UI 갤러리는 공개 정적 호스팅에 보존된 화면 모음이며, 여기에 포함된 미출시 도구와 숙제표 등 서비스 기능은 기존 운영 홈페이지에 반영되지 않았습니다.
